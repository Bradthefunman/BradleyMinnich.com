# BradleyMinnich.com

A personal site for Bradley Minnich — built to serve three audiences from one clear story:

- Fans who want the latest ideas, media, and projects
- Brands and collaborators looking for a creator with a point of view
- Hiring teams looking for a builder who can move between creative and execution

## Structure

The site is a lightweight static homepage with anchor-based navigation:

- About: concise positioning and story
- Selected work: social, brand, venture, and development lanes
- Media: links back to the current journal
- Collaborate: partnership and project fit
- Roles: professional areas of interest
- Contact: direct next steps for messages and briefs

## Run locally

Open `index.html` in a browser, or serve the directory with any static web server.

## Notes

The first version uses only HTML, CSS, and vanilla JavaScript so it can deploy easily to GitHub Pages or another static host.
